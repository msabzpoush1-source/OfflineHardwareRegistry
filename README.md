# OfflineHardwareRegistry

اسکلت اولیه اپلیکیشن اندروید با Kotlin، Jetpack Compose و Room.

- حداقل Android 8.0 (API 26)
- رابط فارسی و پشتیبانی RTL
- ساخت APK آزمایشی با GitHub Actions

پس از بارگذاری فایل‌ها در شاخه main، به Actions بروید و گردش کار Build Android APK را اجرا کنید. فایل APK از بخش Artifacts قابل دریافت است.

**توجه:** این بسته فقط برای آزمایش زنجیره ساخت ابری است؛ امکانات محصول نهایی شامل ثبت دستگاه و قطعه، تاریخچه، پیش‌نویس، ZIP و ادغام با سامانه مرکزی هنوز پیاده‌سازی نشده‌اند.
